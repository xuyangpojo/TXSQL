# SQL优化器性能数据收集方法

本文档说明如何收集和分析SQL优化器的性能数据。

## 一、数据收集目标

1. **优化时间**: 优化器选择执行计划的时间
2. **执行成本**: 优化器估算的执行成本
3. **实际执行时间**: 查询实际执行时间
4. **成本估算准确性**: 估算成本 vs 实际成本
5. **执行计划质量**: 选择的计划是否最优

### 方法2: 使用MySQL EXPLAIN（真实环境）

如果使用真实的MySQL/TXSQL，可以使用EXPLAIN收集数据。

#### 收集执行计划
```sql
-- 启用优化器跟踪
SET optimizer_trace="enabled=on";
SET optimizer_trace_max_mem_size=1000000;

-- 执行查询

-- 查看优化器跟踪
SELECT * FROM information_schema.optimizer_trace\G
```

#### 收集成本信息
```sql
-- 使用EXPLAIN FORMAT=JSON获取详细成本
EXPLAIN FORMAT=JSON 
SELECT o.order_id, c.customer_name
FROM orders o JOIN customers c ON o.customer_id = c.customer_id
WHERE o.order_date > '2023-01-01';
```

#### 收集实际执行时间
```sql
-- 使用EXPLAIN ANALYZE（MySQL 8.0.18+）
EXPLAIN ANALYZE
SELECT * FROM orders WHERE customer_id = 12345;
```

#### 自动化脚本
创建 `collect_performance.sh`:
```bash
#!/bin/bash

QUERY_FILE="test_queries.sql"
OUTPUT_FILE="performance_data.csv"

echo "query_id,query_text,estimated_cost,actual_time_ms,rows_examined,rows_returned" > $OUTPUT_FILE

query_id=1
while IFS= read -r query; do
    if [[ -z "$query" ]] || [[ "$query" =~ ^# ]]; then
        continue
    fi
    
    # 执行EXPLAIN获取估算成本
    cost=$(mysql -u root -e "EXPLAIN FORMAT=JSON $query" | jq '.[0].query_block.cost_info.query_cost')
    
    # 执行查询并测量时间
    start=$(date +%s%N)
    mysql -u root -e "$query" > /dev/null 2>&1
    end=$(date +%s%N)
    time_ms=$(( (end - start) / 1000000 ))
    
    # 获取实际行数
    rows=$(mysql -u root -e "$query" | wc -l)
    
    echo "$query_id,\"$query\",$cost,$time_ms,$rows" >> $OUTPUT_FILE
    
    query_id=$((query_id + 1))
done < $QUERY_FILE
```

### 方法3: 使用Performance Schema（MySQL 5.6+）

#### 启用Performance Schema
```sql
-- 启用语句统计
UPDATE performance_schema.setup_instruments 
SET ENABLED = 'YES', TIMED = 'YES' 
WHERE NAME LIKE 'statement/%';

-- 启用事件消费者
UPDATE performance_schema.setup_consumers 
SET ENABLED = 'YES' 
WHERE NAME LIKE 'events_statements%';
```

#### 查询性能数据
```sql
-- 查看SQL执行统计
SELECT 
    SQL_TEXT,
    COUNT_STAR as executions,
    SUM_TIMER_WAIT/1000000000000 as total_time_sec,
    AVG_TIMER_WAIT/1000000000000 as avg_time_sec,
    SUM_ROWS_EXAMINED as rows_examined,
    SUM_ROWS_SENT as rows_sent
FROM performance_schema.events_statements_summary_by_digest
WHERE SQL_TEXT LIKE '%orders%'
ORDER BY SUM_TIMER_WAIT DESC
LIMIT 10;
```

## 三、性能指标定义

### 1. 优化时间（Optimization Time）
- **定义**: 优化器选择执行计划的时间
- **单位**: 毫秒
- **目标**: < 10ms（简单查询），< 100ms（复杂查询）

### 2. 执行成本（Execution Cost）
- **定义**: 优化器估算的查询执行成本
- **单位**: 成本单位（相对值）
- **用途**: 比较不同执行计划

### 3. 成本估算误差（Cost Estimation Error）
- **定义**: |估算成本 - 实际成本| / 实际成本
- **目标**: < 20%

### 4. 计划质量（Plan Quality）
- **定义**: 实际执行时间 / 最优计划执行时间
- **目标**: < 1.2（即不超过最优计划的20%）

## 四、数据收集脚本

### Python脚本：自动化数据收集

创建 `collect_performance.py`:

```python
#!/usr/bin/env python3
"""
SQL优化器性能数据收集脚本
"""

import subprocess
import json
import time
import csv
import sys

def run_query(query, use_explain=False):
    """执行查询并返回结果"""
    if use_explain:
        cmd = f'mysql -u root -e "EXPLAIN FORMAT=JSON {query}"'
    else:
        cmd = f'mysql -u root -e "{query}"'
    
    try:
        result = subprocess.run(cmd, shell=True, capture_output=True, text=True)
        if use_explain:
            # 解析JSON
            output = result.stdout
            # 提取成本信息
            # ... 解析逻辑
            return {}
        else:
            return result.stdout
    except Exception as e:
        print(f"Error: {e}")
        return None

def measure_execution_time(query):
    """测量查询执行时间"""
    start = time.time()
    result = run_query(query)
    end = time.time()
    return (end - start) * 1000, result  # 返回毫秒

def collect_performance_data(queries_file, output_file):
    """收集性能数据"""
    with open(queries_file, 'r') as f:
        queries = [line.strip() for line in f if line.strip() and not line.startswith('#')]
    
    results = []
    for i, query in enumerate(queries, 1):
        print(f"执行查询 {i}/{len(queries)}: {query[:50]}...")
        
        # 获取执行计划
        explain_result = run_query(query, use_explain=True)
        
        # 测量执行时间
        exec_time, result = measure_execution_time(query)
        
        results.append({
            'query_id': i,
            'query': query,
            'execution_time_ms': exec_time,
            'estimated_cost': explain_result.get('cost', 0),
            # ... 其他指标
        })
    
    # 保存到CSV
    with open(output_file, 'w', newline='') as f:
        writer = csv.DictWriter(f, fieldnames=results[0].keys())
        writer.writeheader()
        writer.writerows(results)
    
    print(f"数据已保存到 {output_file}")

if __name__ == '__main__':
    queries_file = sys.argv[1] if len(sys.argv) > 1 else 'test_queries.sql'
    output_file = sys.argv[2] if len(sys.argv) > 2 else 'performance_data.csv'
    collect_performance_data(queries_file, output_file)
```

## 六、基准测试

### TPC-H基准测试

TPC-H是标准的数据库性能基准测试。

#### 使用TPC-H
1. 下载TPC-H工具: http://www.tpc.org/tpch/
2. 生成测试数据
3. 运行查询
4. 收集性能数据

#### 自定义基准测试

创建 `benchmark.py`:
```python
import time
import statistics

class OptimizerBenchmark:
    def __init__(self):
        self.results = []
    
    def run_benchmark(self, queries, iterations=10):
        """运行基准测试"""
        for query in queries:
            times = []
            for _ in range(iterations):
                start = time.time()
                # 执行优化和查询
                end = time.time()
                times.append((end - start) * 1000)
            
            self.results.append({
                'query': query,
                'avg_time': statistics.mean(times),
                'min_time': min(times),
                'max_time': max(times),
                'std_dev': statistics.stdev(times)
            })
    
    def print_report(self):
        """打印报告"""
        print("基准测试结果:")
        for result in self.results:
            print(f"查询: {result['query'][:50]}")
            print(f"  平均时间: {result['avg_time']:.2f} ms")
            print(f"  最小时间: {result['min_time']:.2f} ms")
            print(f"  最大时间: {result['max_time']:.2f} ms")
            print(f"  标准差: {result['std_dev']:.2f} ms")
            print()
```

## 七、持续监控

### 设置监控脚本

创建 `monitor_optimizer.sh`:
```bash
#!/bin/bash

# 每5分钟收集一次性能数据
while true; do
    timestamp=$(date +%Y%m%d_%H%M%S)
    
    # 收集数据
    mysql -u root -e "
        SELECT 
            NOW() as timestamp,
            SQL_TEXT,
            AVG_TIMER_WAIT/1000000000000 as avg_time_sec
        FROM performance_schema.events_statements_summary_by_digest
        WHERE SQL_TEXT LIKE '%orders%'
        ORDER BY AVG_TIMER_WAIT DESC
        LIMIT 10;
    " >> optimizer_monitor_${timestamp}.csv
    
    sleep 300  # 5分钟
done
```
