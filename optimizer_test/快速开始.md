# SQL优化器测试程序 - 快速开始指南

## 在Windows上运行

### 最简单的方法（如果已安装MinGW或MSVC）

1. **打开命令提示符（CMD）或PowerShell**

2. **进入项目目录**
   ```cmd
   cd C:\projects\TXSQL\optimizer_test
   ```

3. **直接编译运行**
   ```cmd
   REM 如果使用MinGW
   g++ -std=c++11 optimizer_test.cpp -o optimizer_test.exe
   optimizer_test.exe
   
   REM 或者如果使用MSVC（需要先运行vcvarsall.bat）
   cl /EHsc /std:c++11 optimizer_test.cpp /Fe:optimizer_test.exe
   optimizer_test.exe
   ```

### 使用CMake（推荐）

1. **安装CMake**（如果还没有）
   - 下载：https://cmake.org/download/
   - 安装时选择"Add CMake to system PATH"

2. **编译和运行**
   ```cmd
   cd C:\projects\TXSQL\optimizer_test
   mkdir build
   cd build
   cmake ..
   cmake --build .
   bin\optimizer_test.exe
   ```

### 使用提供的批处理脚本

```cmd
cd C:\projects\TXSQL\optimizer_test
build.bat
```

## 如果没有编译器

### 选项1: 安装MinGW-w64
- 下载：https://www.mingw-w64.org/downloads/
- 或者使用MSYS2：https://www.msys2.org/

### 选项2: 安装Visual Studio
- 下载Visual Studio Community（免费）
- 安装时选择"C++桌面开发"工作负载

### 选项3: 使用在线编译器
- 将代码复制到：https://www.onlinegdb.com/online_c++_compiler
- 选择C++语言
- 粘贴代码并运行

## 代码说明

这个程序模拟了SQL优化器的核心功能：

1. **访问路径选择**：选择全表扫描还是索引扫描
2. **连接顺序优化**：决定表的连接顺序
3. **成本估算**：计算不同执行计划的成本

## 修改测试用例

你可以编辑 `optimizer_test.cpp` 中的测试函数来：
- 添加更多表
- 修改表的大小和索引
- 测试不同的查询条件
- 调整成本模型参数

## 常见问题

**Q: 编译错误 "g++不是内部或外部命令"**
A: 需要安装MinGW或配置环境变量

**Q: 找不到CMake**
A: 安装CMake或使用直接编译方法

**Q: 想了解优化器的更多细节**
A: 查看 `SQL_OPTIMIZER_DEVELOPMENT_GUIDE.md` 文件
