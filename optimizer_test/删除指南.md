## 批量删除脚本

创建一个PowerShell脚本 `cleanup.ps1`：

```powershell
# cleanup.ps1 - 清理不需要的文件夹

$projectRoot = "C:\projects\TXSQL"

Write-Host "开始清理不需要的文件夹..." -ForegroundColor Green

# 要删除的文件夹列表
$foldersToDelete = @(
    "storage",
    "mysql-test",
    "boost",
    "extra",
    "client",
    "router",
    "unittest",
    "Docs",
    "man",
    "packaging"
)

foreach ($folder in $foldersToDelete) {
    $path = Join-Path $projectRoot $folder
    if (Test-Path $path) {
        Write-Host "删除: $folder" -ForegroundColor Yellow
        Remove-Item -Path $path -Recurse -Force -ErrorAction SilentlyContinue
        Write-Host "  ✓ 已删除" -ForegroundColor Green
    } else {
        Write-Host "跳过: $folder (不存在)" -ForegroundColor Gray
    }
}

Write-Host "`n清理完成！" -ForegroundColor Green
Write-Host "剩余空间估算..." -ForegroundColor Cyan

# 计算剩余大小
$remaining = Get-ChildItem -Path $projectRoot -Recurse -ErrorAction SilentlyContinue | 
    Measure-Object -Property Length -Sum
$sizeGB = [math]::Round($remaining.Sum / 1GB, 2)
Write-Host "剩余大小: $sizeGB GB" -ForegroundColor Cyan
```

**运行脚本：**
```powershell
cd C:\projects\TXSQL
.\cleanup.ps1
```

## 最激进的方案：只保留测试程序

如果你确定只需要测试程序，可以：

```powershell
# 1. 创建新目录
New-Item -ItemType Directory -Path "C:\projects\SQL_Optimizer_Test" -Force

# 2. 只复制测试程序
Copy-Item -Path "C:\projects\TXSQL\optimizer_test" -Destination "C:\projects\SQL_Optimizer_Test\optimizer_test" -Recurse

# 3. 验证文件
Get-ChildItem -Path "C:\projects\SQL_Optimizer_Test\optimizer_test" -Recurse

# 4. 测试编译
cd "C:\projects\SQL_Optimizer_Test\optimizer_test"
g++ -std=c++11 optimizer_test.cpp -o optimizer_test.exe
.\optimizer_test.exe

# 5. 如果测试成功，可以删除原项目（谨慎！）
# Remove-Item -Path "C:\projects\TXSQL" -Recurse -Force
```

这样你只需要几KB到几MB的空间！

## 总结

| 方案 | 保留内容 | 空间占用 | 推荐度 |
|------|---------|---------|--------|
| **方案1** | 只保留 `optimizer_test/` | ~100KB | ⭐⭐⭐⭐⭐ 强烈推荐 |

| **方案3** | 保留完整项目 | ~10-20GB | ⭐ 不推荐 |

**我的建议：使用方案1，只保留测试程序！**
